## 🌌 Aniverse v1.0.1

### 🛠️ Tech Stack & Technologies
- 📱 **Android Native:** Kotlin + Jetpack Compose + AndroidX Media3 ExoPlayer + SQLite + Jsoup
- 💻 **Desktop:** Electron + NSIS custom directory installer & portable mode
- ⚛️ **Frontend:** React 18 + Vite (Tailwind CSS v4 & Framer Motion)
- 🟢 **Backend:** Embedded local Express runtime on localhost:5000
- 📡 **Metadata:** AniList GraphQL live AiringSchedule & metadata
- 🎬 **Streaming:** Multi-server scraping with MegaPlay video embeds & intro/outro skip times
- 💾 **Storage:** 100% offline local storage with JSON export/import

### 🚀 What's New in v1.0.1:
- 📱 **Native YouTube-Smooth Android App:** Standalone Android app built in Native Kotlin + Jetpack Compose + ExoPlayer. Features 120Hz smooth animations, gesture controls (double-tap to seek, vertical swipe for volume/brightness), native Picture-in-Picture (PiP), and an ultralight **3.68 MB** footprint!
- 📡 **Real Live Airing Episodes:** Switched from static database updates to AniList's live AiringSchedule API.
- 🎯 **Matches Reference Sites 1-to-1:** Shows newly aired episodes with accurate episode badges (SUB 162, SUB 3, etc.).
- 🇨🇳 **Chinese (Donghua) Filter:** Dedicated filter for popular Chinese anime releases.
- 🏴‍☠️ **Custom App Icon:** Integrated pirate-themed branding across Windows executable and Android launcher mipmaps.
